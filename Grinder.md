### 

### **Grind Hard or Go Home**

### **Phase 1**

### **Foundation & game design**

- [ ] ### Define points system: 

      - [ ] ### application \= 1pt, 

      - [ ] ### rejection \= 10pt, 

      - [ ] ### interview \= 100pt

- [ ] ### Sketch core user flows: log in, add application, view leaderboard

- [ ] ### Pick tech stack (e.g. React \+ Supabase or Next.js \+ Firebase)

- [ ] ### Set up project repo, linting, and CI

- [ ] ### Design DB schema: users, applications, statuses, groups/leagues

### **Phase 2**

### **Core app \- auth & tracking**

- [ ] ### Auth: sign up, log in, invite link generation

- [ ] ### Application logger: add/edit/delete an application with status

- [ ] ### Status transitions: Applied → Rejected / Interview / Offer

- [ ] ### Points engine: auto-calculate points on each status change

- [ ] ### Basic dashboard: your own stats and point total

### **Phase 3**

### **Leaderboard & social layer**

- [ ] ### Groups/leagues: create a league, share invite link, join a friend's league

- [ ] ### Leaderboard view: daily / weekly / monthly tabs with rankings

- [ ] ### Anonymized mode option (show initials only) for privacy

- [ ] ### Streak system: reward consecutive days of applying

- [ ] ### Basic email/push nudge: "Alice overtook you today\!"

### **Phase 4**

### **Polish & launch prep**

- [ ] ### Mobile-responsive UI cleanup

- [ ] ### Achievements/badges: "First interview", "10-day streak", etc

- [ ] ### Landing page with value prop and sign-up CTA

- [ ] ### Rate limiting \+ abuse prevention on points system

- [ ] ### Beta test with 5–10 real users, fix top issues

### **Phase 5**

### **Launch & Iterate**

- [ ] ### Public launch: Product Hunt, Reddit r/cscareerquestions, LinkedIn

- [ ] ### Analytics: track DAU, applications logged, leaderboard views

- [ ] ### Feedback loop: in-app "suggest a feature" button

- [ ] ### Monetization exploration: Pro league features, custom badges
